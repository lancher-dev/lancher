# Introduction

**lancher** is a local project-template manager written in Go. It stores templates from directories, ZIP files or git repositories on your machine and creates new projects from them.

## Quick Start

```bash
# Add a template from a git repository, a directory or a ZIP file
lancher add gh:owner/repo

# Create a project from it
lancher new

# See what is installed
lancher list
```

Start with the [installation](/docs/getting-started/installation), then read how to [manage templates](/docs/usage/templates) and [create projects](/docs/usage/creating-projects).
